## On-site copy ready for the study entry point

**Headline:** Learn the periodic table one element at a time.

**Supporting copy:** Look up an element, compare its properties, then test what you remember. Elementa pairs readable reference pages with quizzes, simplified electron-shell views and your own study notes.

**Primary button:** Start studying

**Secondary button:** Explore all118 elements

**Privacy line, only after source verification:** Your notes and progress stay in this browser. Export a backup to keep a copy or move it to another device.

**Reference-page cross-link:** See this element’s electron shells and add it to your study deck.

The shell display should remain labeled as a simplified model. Don’t imply that orbitals are literal planetary paths. Keep official reference links visible so students can check the source.

## A bounded first distribution test

Start with one approved post that reaches students revising introductory chemistry. Use the tagged study URL above. Read results after72hours and again after7days, with fixedUTC windows and ownerQA excluded where it can be identified.

The useful activation is a completed quiz session, with a secondary signal of opening an element and comparing two elements. Landing visits alone don’t show that the tool helped. If at least five sessions, excluding identified owner QA, complete a quiz, review missed questions and one actual usability response before extending distribution. This is an experiment threshold, not a promised conversion rate.

Keep tracking event payloads free of notes, quiz answers and personal text. If the current companion does not emit quiz-complete, record that measurement gap and use its existing verified events rather than pretending the signal exists.
