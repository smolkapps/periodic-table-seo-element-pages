# Chrome extension packaging

The extension is the same Elementa build, loaded from the extension's own origin.
It needs **no permissions** and makes no remote calls: progress is stored in the
extension's own `localStorage`, so it persists across browser restarts and stays
on the device.

## Build the extension folder

```bash
VITE_PACKAGED=true vite build     # or: npm run build:packaged
rm -rf packaging/chrome-extension/dist
cp -r dist packaging/chrome-extension/dist
```

`VITE_PACKAGED=true` does two things this target needs:

- emits relative asset URLs (`./assets/...`), because extension pages are served
  from `chrome-extension://<id>/` with no server rewrite;
- switches the router to hash routing (`#/element/iron`), so deep links work.

## Assemble the unpacked extension

```text
packaging/chrome-extension/
  manifest.json          <- this folder
  dist/                  <- copied build output
  icons/icon-32.png
  icons/icon-48.png
  icons/icon-128.png
```

`manifest.json` points `default_popup` at `index.html` at the extension root, so
copy the build contents to the extension root instead of a `dist/` subfolder, or
edit the path to `dist/index.html`:

```bash
cp -r dist/. packaging/chrome-extension/
mkdir -p packaging/chrome-extension/icons
cp public/icons/icon-32.png public/icons/icon-48.png public/icons/icon-128.png \
   packaging/chrome-extension/icons/
```

## Test locally (no store account needed)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select `packaging/chrome-extension`
4. Click the toolbar icon, study a few elements, close and reopen the popup to
   confirm progress persists; then disconnect the network and confirm the app
   still loads.

## Chrome Web Store checklist (owner actions)

- [ ] Register a developer account (one-time fee, currently US$5) — owner only.
- [ ] Host a privacy policy URL. Use the in-app `/privacy` page content; the store
      listing needs a publicly reachable HTTPS URL.
- [ ] Complete the **Privacy practices** tab: declare *no* data collection, and
      justify the empty permission list (nothing is requested).
- [ ] Single purpose statement: "Offline chemistry study reference and quiz."
- [ ] Confirm no remote code: all JS ships inside the bundle.
- [ ] Upload the ZIP, add screenshots (1280×800 or 640×400) — owner action.
- [ ] Store icon: `public/icons/icon-128.png` is generated by `npm run icons`.

Notes:

- The extension cannot be published or signed from this project; those steps run
  in the Chrome Web Store developer dashboard.
- Popups are capped around 800×600 CSS px, so the periodic table scrolls
  horizontally inside the popup on narrow windows. If that feels cramped, use
  `chrome.windows.create` from a service worker instead of a popup — that change
  is not part of this packaging set.
